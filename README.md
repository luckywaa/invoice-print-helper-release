# 发票打印助手

浏览器本地运行的**发票拼版打印工具**：批量识别发票 PDF/OFD，自动拼版到 A4 打印，并按报销科目分类统计。

**纯本地、零安装、零联网**——所有识别与拼版都在你自己的电脑上完成，发票文件不会被上传到任何地方。

## 下载使用

1. 进入 [Releases（版本下载）](../../releases) 页面，下载最新版压缩包 `invoice-print-helper-vX.Y.Z.zip`
2. 解压到任意位置
3. 双击 `index.html`，用 **Edge / Chrome** 打开
4. 把发票文件（或整个文件夹）拖进页面即可

整个文件夹就是完整应用，可以拷给同事、换电脑使用。详细功能与常见问题见压缩包内的**《使用说明.md》**。

## 主要功能

- **导入识别**：拖文件/文件夹批量导入 PDF/OFD，自动识别票种（数电普票/专票、铁路电子客票、航空行程单）、票面金额与发票号，同号自动去重
- **A4 拼版**：2 张/A4、3 张/A4、智能分析；铁路客票行式布局自动排布；电子章矢量保留不丢
- **页边标注**：每页装订边自动印"合计金额￥xx.xx元，请在背面签字"；专票副本页顶印"进项抵扣专用，单独提交财务"
- **四个打印任务**：① 智能拼版 ② 专票副本 ③ 纸质凭据粘贴单（可选张数） ④ 报销贴票说明 / 凭据打印双面版 docx 下载
- **报销统计**：机票/火车/大巴/住宿/市内交通/其他 六类自动统计，CSV 明细导出

## 隐私说明

- 纯本地运行：不联网、无后端、无统计埋点，发票数据不出你的电脑
- 设置只保存在浏览器本地，可随时导出/清空
